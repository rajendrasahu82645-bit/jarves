# Contributing

Thanks for contributing to Jarvis AI.

## Development

- Python 3.10 or newer is required.
- Install voice dependencies with `python -m pip install -r requirements.txt`.
- Keep API credentials in environment variables; never commit them.
- Run the tests with `python -m unittest discover -s tests -v`.

## Changes

Keep changes focused, add tests for behavior changes, and update the README when setup or user-facing behavior changes.
