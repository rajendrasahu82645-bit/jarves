# 🤖 JARVIS AI Assistant

> A smart voice-controlled personal AI assistant built with Python.

## 📌 About the Project

**JARVIS AI Assistant** is a Python-based personal voice assistant that can understand voice commands and perform different tasks such as searching the web, opening applications, telling the time and date, speaking responses, and more.

The project is designed to provide a simple **hands-free AI assistant experience** using Speech Recognition and Text-to-Speech technologies.

## ✨ Features

- 🎙️ Voice Command Recognition
- 🗣️ Text-to-Speech Response
- 🌐 Web Search
- 🔎 Google Search
- 📺 YouTube Search
- 🕒 Current Time & Date
- 📂 Open Applications
- 💻 Computer Control
- 🎵 Play Music
- 💬 Conversational Responses
- ⚡ Fast Voice-Based Interaction

## 🛠️ Technologies Used

- **Python**
- **SpeechRecognition**
- **pyttsx3**
- **PyAudio**
- **Web Browser / Web APIs**
- **Python Standard Libraries**

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/JARVIS.git
```

### 2. Open the Project

```bash
cd JARVIS
```

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

Or install the main packages manually:

```bash
pip install SpeechRecognition
pip install pyttsx3
pip install PyAudio
```

### 4. Run JARVIS

```bash
python jarvis.py
```
